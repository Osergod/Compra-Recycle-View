# Compra-Recycle-View

Prepara una Aplicació a la qual hi hagi una activitat que permeti visualitzar una llista de productes a comprar, cadascun amb un nom, preu i una imatge associats. D’aquests productes, s’han de poder afegir/eliminar unitats. S’ha de poder veure quants productes de cada tipus hi ha. Hi ha d’haver un TextView per visualitzar el preu total dels productes afegits.
Al prèmer un botó, s’ha d’obrir una nova activitat a la que es vegi un resum dels productes, s’ha de poder tornar a la activitat anterior i també “confirmar” la compra, mostrant per consola un missatge de quins productes es volen comprar.
Per ambdues Activitats, s’ha d’utilitzar RecycleView.
